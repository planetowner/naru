# 디자인 시스템

현재 화면의 색상, 크기, 간격과 동작을 유지하며 정리한 코드 기준이에요. 실제로 같은 역할과 값을 사용하는 부분만 공유해요. 비슷한 숫자를 가까운 토큰 값으로 반올림하지 않아요.

이후 검토에서 승인한 색상 변경은 반영해요. 채팅 상단 이름·아이콘·미읽음 수와 기본 입력창의 글자·첨부·음성 아이콘은 `AppColors.textPrimary`(`#191F28`)로 통일했어요.

## 아이콘

앱에서 지정하는 UI 아이콘은 [AppIcons](../mobile/lib/design_system/app_icons.dart)의 Google Material Symbols Rounded로 통일했어요. 굵기 400·광학 크기 24·GRAD 0을 고정하고, 기본은 선형(FILL 0), 재생·일시정지·정지는 채움형(FILL 1)을 사용해요. 재생 상태에 따른 전환은 `AppIcons.playback`을 공유해요.

기존 Material·Cupertino 아이콘과 직접 그리던 뒤로 가기·편집·저장·공유·확인·업로드 사진·영상 재생 도형을 교체했어요. 버튼의 크기·위치·색상·동작은 유지했어요. 브랜드 로고와 운영체제가 제공하는 카메라·공유·PencilKit 도구는 이 UI 아이콘 규격의 대상이 아니에요.

사용하는 심벌 44개를 담은 두 정적 글꼴과 Apache 2.0 라이선스를 앱에 포함했어요. 런타임 다운로드와 추가 아이콘 패키지 없이 기존 `Icon`·`IconData`를 사용해요. Flutter 기본 UI가 빌드 중 참조하는 `cupertino_icons` 의존성은 유지하고, 앱 코드의 아이콘은 `AppIcons`만 사용해요. [원본 요청·이름 대응표](../mobile/assets/fonts/material_symbols/README.md)에서 Google 이름과 코드 정의를 확인할 수 있어요.

## 채팅 검색 확장과 Yeoul 컨트롤

[Yeoul 버튼·입력 규격](https://www.figma.com/design/5s4HDO8iI8FIHDcTfkS2N2?node-id=45-291)을 공통 컨트롤에 적용했어요. [AppControlStyle](../mobile/lib/design_system/app_control_style.dart)에서 버튼 높이 46·반경 10·14 Bold, 입력 높이 46·반경 8·14 Regular·흰 배경·1px `#D8DEE5` 테두리를 관리해요. Yeoul에 없는 포커스·오류·비활성 색상은 기존 Naru 역할 토큰을 사용해요. 메시지 작성기는 여러 줄과 별도 배치 규칙이 있어서 기본 입력의 최소 높이를 적용하지 않아요.

### Pretendard 타이포그래피

[Yeoul 타이포그래피](https://www.figma.com/design/5s4HDO8iI8FIHDcTfkS2N2?node-id=45-385)의 확정 글꼴 Pretendard와 역할별 규격을 가져왔어요. [AppTypography](../mobile/lib/design_system/app_typography.dart), 앱 테마, 공통 버튼·입력, 검색 화면이 함께 사용해요. 굵기는 원본의 Regular 400·Bold 700으로 통일했어요. 기존 Medium은 Regular, Semibold는 Bold로 연결했어요.

| 역할 | 코드 | 크기·굵기 |
| --- | --- | --- |
| 시작·큰 제목 | `display` / `heading` / `subheading` | 28 / 26 / 24 Bold |
| 화면·카드·섹션 제목 | `screenTitle` / `cardTitle` / `sectionTitle` | 22 / 19 / 18 Bold |
| 강조·중간 본문 | `bodyLarge` / `bodyMedium` | 16 / 15 Regular |
| 기본·보조 본문 | `body` / `bodySmall` | 14 / 13 Regular |
| 버튼·입력 라벨 | `button` / `fieldLabel` | 14 / 12 Bold |
| 설명 | `caption` / `captionSmall` / `finePrint` | 12 / 11 / 10 Regular |
| 코드 표기 | `code` | 32 Bold |

공통 역할은 행간 Auto·자간 0이에요. Flutter에서는 `kTextHeightNone`으로 글꼴 기본 행간을 사용해요. 한 줄 입력은 실제 글꼴의 행간에 맞춰 세로 여백을 계산하므로 기본 글자 배율에서 아이콘 유무와 오류 문구에 관계없이 테두리 높이가 46이에요.

채팅 말풍선 16/24, 시간 표시, 미디어 컨트롤처럼 배치에 연결된 기존 크기·행간은 전용 규격으로 유지해요. 이들도 글꼴은 Pretendard를 사용해요. 기존 숫자 이름의 스타일은 이 전용 배치에 남겨 두고, 새 공통 화면에는 역할 이름을 사용해요.

앱에는 [공식 Pretendard](https://github.com/orioncactus/pretendard) 1.3.9의 Regular·Bold 원본 OTF와 [OFL 라이선스](../mobile/assets/fonts/OFL.txt)를 포함했어요. 런타임 다운로드 없이 사용하며, 글꼴에 없는 문자는 플랫폼의 기본 대체 글꼴로 표시해요.

[Naru 디자인 시스템](https://www.figma.com/design/GWkDUUxGKUXshtMMFVHAP9?node-id=30-307)의 글자 표본·버튼·입력·사용처 표와 [검색 시안](https://www.figma.com/design/GWkDUUxGKUXshtMMFVHAP9?node-id=48-200) 및 프로토타입도 갱신했어요. `AppTypography/*`는 공통 역할, `Feature/*`는 기존 전용 행간, `Archive/iOS/*`는 이전 참조 스타일이에요.

[검색 확장 시안](https://www.figma.com/design/GWkDUUxGKUXshtMMFVHAP9?node-id=48-200)은 메시지·사진/영상·링크·파일 네 탭이에요. `chat_search.dart`가 검색 대상과 필터 규칙을, `chat_search_widgets.dart`가 탭·날짜 필터·격자·카드·빈 결과를 관리해요. 링크와 파일은 같은 카드 레이아웃을 쓰고 내용과 미리보기만 달라요. 카드 미리보기 높이 104·설명 영역 128과 격자 배치는 `_SearchResultCard`에서 관리해요. 링크 미리보기·카드 표면과 글자 확대에 따른 카드 높이 계산이 같은 규격을 참조해요.

- 기존 대화 페이지 API로 전체 기록을 순서대로 읽어요. 읽는 동안 누적 결과와 진행 상태를 보여주며, 실패하면 마지막 커서부터 재시도해요. 별도 검색 서버나 데이터 변경은 없어요.
- 메시지는 원문·번역·답장 인용을 검색하고 기존 말풍선으로 이동해요. 아직 화면에 없는 결과는 기존 메시지 구간 로더로 가져와요. 결과로 이동할 때는 상단 검색 영역과 하단 검색 바를 제외한 범위 안에 말풍선을 배치해요. 키보드가 닫히는 중에도 하단 바 위의 간격을 유지해요. 검색을 열 때는 대화의 배치 기준을 유지해요. 상단 검색 영역은 겹쳐지는 범위로만 계산하므로 짧은 대화도 다시 아래로 밀리지 않아요.
- 결과 개수는 하단 `현재/전체`로만 표시해요. 상단의 `matches`·`Newest first`와 빈 상태 행은 제거했어요. 기록 로딩·실패·재시도는 필요한 동안 표시해요. 제목과 입력창 뒤는 흰 배경을 유지하고, 탭 아래는 일반 채팅의 `_TranslucentTopBarSurface`를 공유해요. 페이드 끝 여백은 `space12`예요.
- 사진·영상은 첨부 파일명, 링크는 제목·주소, 파일은 파일명으로 검색해요. 한 메시지의 여러 사진·링크도 개별 결과예요. 사진·영상으로 보낸 자료와 파일로 보낸 자료는 전송 유형에 따라 구분해요.
- 사진·영상·링크·파일의 날짜 버튼은 높이 56인 필터 행 오른쪽에 같은 `AppIconButton`을 사용해요. 날짜 선택 후에는 공통 필터 칩에 날짜와 닫기 아이콘을 표시하고, 누르면 날짜 조건을 해제해요. 날짜를 고르기 전에는 날짜 문구가 없어요. 메시지의 날짜 이동은 하단 입력창 공통 컨테이너 안에서 원형 배경 없는 달력 아이콘을 사용해요.
- 미디어는 기존 썸네일·뷰어를 공유해요. 검색 격자에서는 선택한 영상만 내려받아요. 링크 열기와 파일 미리보기도 기존 동작을 공유해요.
- 파일 모델에는 문서 썸네일이 없어서 파일 아이콘을 표시해요. PDF 첫 페이지나 동영상 프레임을 별도로 생성하지 않아요. 시안의 예시 이미지·파일은 제품 코드에 포함하지 않아요.

## 음성 메시지 텍스트 변환

새 음성 메시지는 전송 후 자동으로 텍스트로 변환해요. 기존 흰 음성 카드의 재생 영역 높이 56·파형·버튼은 유지하고, 아래에 메시지 공통 본문과 좌우 여백을 사용해 전사 텍스트를 표시해요. 하단 여백은 `AppSpacing.space12`예요.

발신·수신 음성 카드는 같은 텍스트 빌더를 사용해요. 수신자는 문자 메시지처럼 텍스트를 눌러 원문과 번역을 전환할 수 있어요. 원문·번역·검색 강조는 기존 본문 컴포넌트를, 전사·번역의 처리 중·실패·재시도는 `_MessageProcessingStatus`를 공유해요. 한국어·중국어 안내를 사용자 언어에 맞춰 표시해요. 이전 음성 메시지는 기존 재생 카드로 유지해요.

## 공통화 기준

같은 구조·동작은 하나의 컴포넌트나 함수에서 관리하고 문구·아이콘·데이터만 전달해요. 기존 토큰의 단순 별칭이나 한 번만 쓰는 스타일을 위한 별도 파일은 만들지 않아요. 배치와 계산이 함께 참조하는 치수는 실제 컴포넌트 가까이에 한 번 정의해요.

2026-10-27 재정리에서 별도 스타일 파일 20개를 제거했어요. 아래 예외 표의 승인된 모양·동작은 유지하며, 관리 위치만 기존 위젯으로 옮겼어요. 메시지·입력창·시트처럼 실제로 여러 구현이 공유하는 규칙은 `ChatMessageStyle`·`ChatComposerStyle`·`ChatActionSheetStyle`에 남겨요.

사진·영상 뷰어 상하단, 사진 편집 상단, 영상 트림 컨트롤의 슬라이드·페이드·터치 차단은 `AppMediaViewerControlsTransition` 하나로 공유해요. 기존 200ms·곡선·이동 방향·위젯 키를 유지하고 표시 여부·방향·내용만 전달해요.

## 공통 컴포넌트의 역할

메시지 입력창은 여러 줄 입력, 답장·수정 문맥, 키보드와 첨부 패널 배치를 처리해요. 로그인용 `AppTextField`의 `TextFormField`와 구조·장식이 달라서 교체하지 않아요. 기본 입력과 메시지 검색 하단은 `_ComposerSurface`의 높이·배경·테두리·모서리·패딩을 공유해요. 답장과 수정은 기존 `_buildContextComposer`, 모든 입력 상태는 `_buildTextField`, 원형 액션은 `_ComposerCircleButton`을 공유해요. 첨부·녹음·검색 이동은 같은 `.neutral` 버튼 규격을 사용하며 검색 이동의 비활성 아이콘은 `textDisabled`예요. 스타일은 `ChatComposerStyle`에서 전달하며, 버튼 교체와 아이콘 교체의 동일한 페이드·크기 전환은 `_buildComposerActionSwitcher`를 공유해요.

미디어 상단 버튼은 일반 제출 버튼과 크기·모양·배경이 달라요. 일반 `AppButton`으로 바꾸지 않고 미디어용 공통 컴포넌트를 사용해요.

## 이번에 연결한 규칙

- 채팅 목록·메시지·사진 선택기의 패딩과 간격 중 기존 스케일과 일치하는 값을 `AppSpacing`에 연결했어요. 사용 중이던 4 간격과 4 모서리도 공통 토큰으로 연결했어요.
- 동일한 모서리 값은 `AppRadius`로 연결했어요. 17 말풍선과 14 미디어 모서리는 `ChatMessageStyle`에서 별도로 공유해요.
- 본문·파일·링크 메시지의 배경은 `_MessageBubble`이 방향에서 결정해요. 호출부가 방향과 색상을 따로 지정하던 중복을 제거했어요.
- 수신·발신·링크 본문과 통화 본문의 글자 스타일은 `ChatMessageStyle.body`에서 공유해요. 통화 카드는 양쪽 모두 흰 배경이므로 기본 글자색을 유지해요.
- 메시지 묶음 간격 5, 시간 표시 간격 6, 말풍선 좌우/상하 패딩 11/6을 `ChatMessageStyle`로 연결했어요. 일반 메시지·링크·사진·영상의 화면 너비 제한 68%와 답장 너비 36~70%도 같은 규격에서 관리해요. 링크·미디어 카드의 별도 최대 크기는 유지해요.
- 말풍선 꼬리는 크기 12×13, 위쪽 위치 6, 바깥쪽 위치 -7을 `ChatMessageStyle`에서 관리해요. 꼬리 위치와 본문 패딩은 역할이 다르므로 별도 값으로 유지하고, 방향별 도형과 강조 애니메이션은 기존 구현을 사용해요.
- 답장 인용·수정 표시는 방향별 글자·구분선 색상과 간격을 `ChatMessageStyle`에서 관리해요. 답장 구분선 위아래 7 간격은 실제 배치와 크기 측정이 같은 값을 사용해요. 번역 안내는 공통 글자 규격에 상태별 색상을 전달하고, 재시도 버튼은 같은 글자색을 공유해요. 검색 강조는 수신/발신·현재 결과 여부에 따른 기존 네 가지 색상 규칙을 유지해요.
- 수신·발신 링크 카드는 기존 `_LinkPreviewCard`를 공유하고, 스타일은 `_LinkPreviewCard`에서 관리해요. 채팅 이미지는 2:1 비율을 유지하고, 같은 `_LinkPreviewImage`를 사용하는 검색 결과는 기존 높이 104를 전달해요. 이미지 로딩·실패·이미지 없음의 대체 표시와 링크 열기 동작은 기존 구현을 유지해요.
- 통화 기록은 기존 `_CallMessageBubble`을 공유하고, `_CallMessageBubble`에서 위아래 여백 9·아이콘 22·글자 간격 10과 카드 장식을 관리해요. 시작은 `green500`, 부재중은 `red500`, 취소·응답 없음은 `grey500`, 종료는 `grey900`을 사용해요. 수신·발신에 따른 문구·아이콘 선택과 통화 시간 표시, 시작·결과 기록을 따로 남기는 동작은 유지해요.
- 음성 메시지는 수신·발신 모두 기존 `_VoiceMemoMessageBubble`을 공유하고, `_VoiceMemoMessageBubble`에서 현재 크기와 색상을 관리해요. 재생·일시정지는 기존 `AppIcons.playback`의 Google 채움형 아이콘, 시간 글자는 `ChatMessageStyle.body`를 사용해요. 녹음창과 공유하는 파형 그리기, 재생 위치 저장과 탭·드래그 탐색은 유지해요.
- 파일 메시지는 수신·발신 모두 기존 `_FileMessageContent`를 공유하고, `_FileMessageContent`에서 내용 최대 너비 224·아이콘 표면 38·아이콘 21·간격 10/3을 관리해요. 파일명은 기존 `typography6`·Regular, 용량은 `subTypography12`, 아이콘 모서리는 `AppRadius.borderRadius8`, 문서 아이콘은 `AppIcons.file`을 사용해요. 방향별 색상과 발신 배경/용량의 알파 38/200, 바깥 말풍선과 파일 열기 동작은 유지해요.
- 채팅 입력창은 `ChatComposerStyle`에서 기본 최소 높이 48·모서리 24·버튼 32, 답장·수정 모서리 28·액션 42·닫기 34를 관리해요. 기본 글자 15·답장/수정 글자 16과 기본 안내 문구 `#92989E`도 유지해요. 답장·수정은 같은 규격과 배치를 공유하며, 입력창 크기 전환 180ms와 버튼·아이콘 전환 140ms를 한곳에서 관리해요. 입력 상태·전송 가능 조건·콜백·포커스와 키보드/첨부 패널 배치 계산은 기존 구현을 유지해요.
- 채움·테두리 버튼의 최소 크기·패딩·모서리와 버튼 글자 스타일, 입력창의 기본·활성·비활성 테두리를 테마 내부에서 공유해요.
- 미디어 제목과 재생 시간의 `#F2F2F2`를 `AppMediaViewerChrome.labelColor`로 모았어요. 아이콘용 `#E8E8E8`과 구분해요.
- 11 크기 알림 배지는 기존 11 타이포그래피에 연결했어요. 영상 시간도 기존 13 타이포그래피를 사용하고 전용 줄 높이·자간만 덮어써요.
- 영상 트림 컨트롤은 말풍선 역할 토큰을 사용하던 연결을 제거했어요. 동일한 `grey100`과 `primary`를 사용하므로 말풍선 색상을 바꿔도 트림 컨트롤까지 바뀌지 않아요.
- 통화 시작·음성 녹음·오디오 출력 시트는 `ChatActionSheetStyle`에서 공통 반경 `AppRadius.radius24`와 용도별 패딩을 관리해요. 출력 선택창의 안전 영역은 `SafeArea`에서 한 번만 더해요.
- 녹음창의 표시줄·조작 버튼은 각 녹음 위젯에서 직접 정의해요. 녹음·정지·다시 녹음·전송은 기존 `_VoiceMemoRoundButton`을 공유하고, 지름 44를 호출부마다 전달하던 중복을 없앴어요. 바깥 원의 여백 5를 양쪽에 더한 전체 높이는 54예요.

위 표의 대표 항목 외에 남아 있는 수치의 파일·클래스·코드 위치는 [개별 스타일 인덱스](design-system-local-values.md)에 모았어요. 도형을 그리는 좌표, 스크롤·제스처 계산, 데이터 처리용 숫자는 일반 간격 토큰과 구분해요.

- [app_appearance_test.dart](../mobile/test/design_system/app_appearance_test.dart#L14)는 시작 화면, 로그인, 최근 채팅, 과거 채팅, 사진 선택기, 사진 편집 상단바를 비교해요. 시작 화면과 로그인 기준 이미지는 승인한 naru 브랜드를 반영했어요.
- 비교 환경은 420×900 논리 픽셀의 Flutter 위젯 테스트예요. 앱에 포함된 Pretendard·아이콘 글꼴과 빈 사진 썸네일을 사용해요. 위젯 테스트에는 실기기 운영체제의 중국어 대체 글꼴이 없으므로 해당 글리프와 네이티브 PencilKit 화면 전체를 검증하지 않아요.
- 시작 화면은 피그마와 같은 390×844 크기로 비교해요.

프로젝트 루트에서 실행해요.

```sh
cd mobile
flutter analyze --no-pub
flutter test --no-pub
```

화면을 의도적으로 바꿀 때만 변경 내용을 확인한 뒤 `flutter test --update-goldens test/design_system/app_appearance_test.dart`로 기준 이미지를 갱신해요. 디자인 시스템 내부 정리만 했다면 기존 이미지 비교를 그대로 통과해야 해요.
