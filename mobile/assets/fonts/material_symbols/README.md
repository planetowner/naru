# Material Symbols Rounded

Google Material Symbols Rounded를 승인한 굵기 400·광학 크기 24·GRAD 0으로 고정한 글꼴이에요. 기본은 FILL 0, 재생·일시정지·정지는 FILL 1을 사용해요. 앱에서 쓰는 심벌만 Google Fonts API로 내려받아 포함하므로 실행 중 다운로드하지 않아요.

- 공식 안내: https://developers.google.com/fonts/docs/material_symbols
- 라이선스: Apache 2.0 (`LICENSE.txt`)
- 원본 글꼴/코드포인트: https://github.com/google/material-design-icons/tree/master/variablefont
- 코드 정의: `lib/design_system/app_icons.dart`

새 아이콘은 공식 이름을 아래 요청의 `icon_names`에 정렬해 추가하고 글꼴과 `AppIcons`를 함께 갱신해요. 같은 역할은 기존 `AppIcons` 정의를 재사용해요.
